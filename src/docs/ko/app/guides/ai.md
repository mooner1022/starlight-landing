**StarLight AI**는 앱 안에서 일하는 AI 에이전트예요. 부탁을 받으면 프로젝트 파일을 읽고 고치고, 컴파일하고, 디버그 룸에서 봇을 시험해 봐요. 아래 탭의 **AI**에서 열어요. Google Play 판과 GitHub 판 모두에서 쓸 수 있어요.

> [!NOTE]
> 보낸 메시지와 첨부 파일, 에이전트가 읽은 프로젝트 파일은 고른 AI 제공자에게 전송돼요. 요금과 사용량 한도는 그 제공자의 정책을 따라요.

## AI 연결하기

처음 열면 **AI 연결하기**가 보여요. **연결하기**를 누르거나 AI 탭의 설정 버튼을 눌러 **AI 설정**을 열고, **AI 제공자**에서 하나를 골라요.

| 제공자 | 연결 방법 |
|---|---|
| **ChatGPT** | ChatGPT 계정으로 로그인해요. 키는 필요 없고, 요청은 ChatGPT 플랜의 한도를 사용해요. |
| **Anthropic** | API 키로 Claude 모델을 써요. 쓴 만큼 결제돼요. |
| **OpenAI** | OpenAI API 키로 써요. ChatGPT 플랜과는 별개로 쓴 만큼 결제돼요. |
| **Google Gemini** | Google AI Studio에서 받은 API 키로 Gemini 모델을 써요. |
| **OpenRouter** | API 키 하나로 여러 회사의 모델을 골라 써요. |
| **OpenAI-compatible** | Ollama처럼 OpenAI 방식을 따르는 서버에 주소로 연결해요. API 키는 선택이에요. |

API 키를 넣고 **저장하고 확인**을 누르면 연결을 확인하고 쓸 수 있는 모델 목록을 받아 와요. 키는 이 기기에 암호화해서 보관하고, 대화를 내보낼 때도 들어가지 않아요. 연결한 뒤에는 AI 탭의 모델 버튼에서 제공자, **모델**, **추론 강도**를 바꿀 수 있어요. 목록에 없는 모델은 ID를 직접 입력해요.

**ChatGPT**를 고르면 브라우저에서 로그인한 뒤 앱으로 돌아와요. OpenAI가 오픈소스 앱에 제공하는 로그인을 쓰고, 사용량은 chatgpt.com에서 확인하고 관리할 수 있어요.

## 대화하기

AI 탭의 입력창에 부탁을 적어 보내면 새 대화가 시작돼요. 입력창 아래의 **새 봇 만들기**, **오류 고치기**, **프로젝트 설명**, **봇 테스트**는 입력창에 예시 문장을 채워 줄 뿐 바로 보내지 않아요.

```text
"/날씨"라고 보내면 오늘 날짜를 답하는 봇을 만들어 줘.
```

에이전트는 필요한 만큼 도구를 쓰며 일해요. 대화에는 지금 하는 일(파일 읽기, 파일 수정, 컴파일, 디버그 룸 테스트 등)과 그 입력과 결과가 차례로 보이고, 파일을 바꾼 도구는 바뀐 줄을 보여 줘요. 프로젝트를 만들거나 파일을 건네면 대화에 카드가 생겨서 **편집**, **디버그 룸**, **설정**이나 **열기**, **공유**, **저장**으로 바로 이어 갈 수 있어요.

- **앱을 닫아도 계속 일해요.** 작업 중에는 알림으로 진행 상황이 보이고, 끝나면 알려 줘요. 여러 대화가 동시에 일할 수도 있어요.
- **일하는 중에도 메시지를 보낼 수 있어요.** 보낸 메시지는 **에이전트가 이어서 읽을 메시지**에 쌓였다가 다음 단계에서 전달돼요. **멈추기**를 누르면 지금 단계에서 멈춰요.
- **에이전트가 질문하기도 해요.** 정할 것이 있으면 선택지를 보여 주고 답을 기다려요. 고르거나 **직접 입력**으로 답해요.
- **긴 작업은 계획을 세워요.** 여러 단계가 필요하면 대화 위에 **계획**이 생기고, 단계마다 완료, 진행 중, 할 일이 표시돼요.
- **대화를 이어서 해도 돼요.** 대화 목록에서 예전 대화를 눌러 다시 열고, 길게 눌러 **이름 바꾸기**나 **대화 삭제**를 해요.

### 프로젝트와 함께 대화하기

[프로젝트 카드](/docs/app/guides/projects#프로젝트-카드)의 **AI** 버튼을 누르면 그 프로젝트를 정해 둔 대화가 시작돼요. 입력창의 **+** 버튼에서도 이 대화의 **프로젝트**를 정하거나 해제할 수 있고, **사진**과 **파일**을 첨부할 수 있어요(파일 하나에 20MB까지).

에이전트는 프로젝트 폴더의 `AGENTS.md`에 그 봇이 하는 일, 파일 구성 같은 메모를 남기고 다음 대화에서 먼저 읽어요. 직접 고쳐도 돼요.

### 확인하고 진행하기

에이전트가 무언가를 바꾸기 전에 **진행할까요?** 를 물으면 **허용**, **거부**, **이 대화에서 항상 허용** 중에 골라요. 무엇을 먼저 물어볼지는 **AI 설정 → 먼저 물어볼 작업**에서 정하고, 대화마다 **+** 버튼에서 따로 정할 수도 있어요.

| 먼저 물어볼 작업 | 하는 일 |
|---|---|
| **묻지 않음** | 수정, 삭제, 켜고 끄기를 스스로 해요. |
| **삭제·켜고 끄기** (기본) | 무언가를 지우거나 프로젝트를 켜고 끄기 전에 물어봐요. |
| **모든 변경** | 컴파일과 테스트를 포함해 프로젝트를 바꾸는 모든 작업 전에 물어봐요. |
| **계획 먼저** | 둘러보고 계획만 세워요. **계획대로 진행**을 누르기 전에는 아무것도 바꾸지 않아요. |

모델 요청이 **한 번에 진행할 단계**(기본 60)만큼 쌓이면 잠시 멈추고 **계속하기**를 기다려요. 앱이 종료됐거나 요청이 실패해 멈춘 작업도 **계속하기**로 이어서 해요.

### 되돌리기와 메시지 고치기

메시지를 길게 누르면 **텍스트 복사**가 나와요. 에이전트가 일하는 중이 아닐 때 내 메시지를 길게 누르면 **해당 대화 수정**과, 그 뒤에 에이전트가 바꾼 것이 있으면 **여기로 되돌리기**도 나와요.

- **여기로 되돌리기**는 그 메시지부터 에이전트가 바꾼 파일과 프로젝트를 그 전으로 되돌려요. **파일만** 되돌리거나 **파일과 대화**를 함께 되돌릴 수 있고, 되돌린 직후에는 **되돌리기 취소**로 다시 적용할 수 있어요.
- 에이전트의 도구가 바꾼 것만 되돌려요. 봇이 실행 중에 쓴 파일은 그대로예요. 목록에 있는 파일은 통째로 돌아가서, 그 뒤에 직접 고친 내용도 함께 바뀌어요. 켜져 있는 프로젝트는 다시 컴파일해요.
- **해당 대화 수정**으로 메시지를 고쳐 보내면 그 메시지 이후의 대화가 지워져요. 그 뒤에 에이전트가 바꾼 것이 있으면 함께 되돌릴지 물어봐요.

### 컨텍스트와 사용량

대화가 길어지면 모델이 한 번에 읽을 수 있는 양을 채워 가요. 대화 화면의 컨텍스트 표시가 80%를 넘으면 이전 대화를 요약해서 이어 가고, 메뉴의 **대화 요약하기**로 직접 요약할 수도 있어요. 메뉴의 **사용량**에서는 이 대화에 쓴 입력, 캐시, 출력 토큰을 볼 수 있어요.

## AI 설정

| 설정 | 설명 |
|---|---|
| **AI 제공자** | 연결할 제공자와 키, 모델을 정해요. 연결을 해제하면 키도 지워요. |
| **먼저 물어볼 작업** | 위의 [확인하고 진행하기](#확인하고-진행하기)를 보세요. |
| **한 번에 진행할 단계** | 모델 요청이 이만큼 쌓이면 멈추고 계속할지 물어봐요. 기본 60이에요. |
| **나만의 지침** | 모든 대화에 함께 보낼 지침이에요. 예: "주석은 한국어로 써 줘." |
| **웹 검색** | Anthropic과 OpenRouter 모델이 필요할 때 웹을 검색해요. 검색 비용은 제공자가 따로 받아요. 기본은 꺼져 있어요. |
| **끝나면 알림** | 다른 화면에 있을 때 작업이 끝나면 알려 줘요. |
| **실시간 업데이트로 진행 상황 표시** | 대화를 보고 있지 않을 때 작업을 상단 칩과 잠금화면 카드로 보여 줘요. Android 16 QPR2 이상에서 동작하고, 삼성 기기는 개발자 옵션의 **모든 앱의 실시간 정보 보기**를 켜야 해요. |
| **대화 이름 자동으로 짓기** | 첫 답변이 끝나면 모델에게 짧은 요청을 한 번 더 보내 대화 이름을 지어요. 끄면 첫 메시지의 첫 줄이 이름이 돼요. |
| **대화 기록** | 모든 대화와 파일을 zip 파일로 **내보내기**하거나 **가져오기**해요. API 키와 설정은 들어가지 않아요. |

GitHub 판은 대화를 `StarLight/agent` 폴더에 저장해서 앱을 다시 설치해도 남아요. Google Play 판은 앱을 지우면 대화도 지워지니, 다시 설치하기 전에 내보내 두세요.

에이전트가 시작한 컴파일의 제한 시간은 앱 [설정](/docs/app/guides/settings)의 **AI 컴파일 제한 시간 (초)** 에서 바꿔요. 홈의 **AI 에이전트** [위젯](/docs/app/guides/home)으로 진행 중인 작업을 보거나 새 부탁을 시작할 수도 있어요.
