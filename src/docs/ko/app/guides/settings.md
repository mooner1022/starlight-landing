**설정** 탭의 항목을 누르면 세부 화면이 열려요. 설정은 `StarLight/config-general.json`에 저장돼요.

## 일반

| 항목 | 설명 |
|---|---|
| **전역 전원** | 모든 프로젝트의 답장과 처리를 켜고 꺼요. 끄면 어떤 프로젝트도 이벤트를 받지 않아요. 기본은 켜짐이에요. |
| **알림 접근 권한** | 허용 상태를 보여 주고, 누르면 시스템 설정으로 가요. |
| **배터리 최적화 예외** | 예외 설정 상태를 보여 주고, 누르면 설정할 수 있어요. |
| **앱 재시작** | 모든 프로세스를 안전하게 종료하고 다시 시작해요. |

## 프로젝트, 플러그인

| 항목 | 설명 |
|---|---|
| **컴파일 애니메이션** | 컴파일이 끝난 뒤 진행 표시줄이 끝까지 차오르는 것을 잠시 보여 줘요. |
| **전역 모듈 로드** | `StarLight/modules` 폴더를 모듈 경로에 넣어서, 여러 프로젝트가 같은 모듈을 쓸 수 있게 해요. 기본은 꺼짐이에요. [모듈 나누기](/docs/neonjs/guides/modules#여러-프로젝트가-함께-쓰는-모듈)를 보세요. |
| **안전 모드** | 플러그인을 불러오지 않고 앱을 실행해요. [플러그인 설치와 관리](/docs/app/guides/plugins#안전-모드)를 보세요. |
| **AI 컴파일 제한 시간 (초)** | [StarLight AI](/docs/app/guides/ai)가 시작한 컴파일이 이 시간 안에 끝나지 않으면 실패로 처리해요. 스크립트가 멈춰도 대화가 끊기지 않게 해요. 기본 60초예요. |

한 프로젝트는 누가 시작하든 한 번에 하나씩만 컴파일돼요.

## 알림, 이벤트

| 항목 | 설명 |
|---|---|
| **수신 메세지 로그 표시** | 받은 메시지를 로그에 남겨요. |
| **패키지 규칙 설정** | 어떤 앱의 알림을 메시지로 읽을지 정해요. 아래에서 설명해요. |
| **onNotificationPosted 이벤트 사용** | 모든 앱의 알림을 `onNotificationPosted` 함수로 전달해요. 레거시의 `onNotificationRemoved`와 API2의 `NOTIFICATION_POSTED`·`NOTIFICATION_REMOVED`도 이 설정을 따라요. 부하가 늘 수 있어요. |
| **문제 해결 도우미** | 권한, 카카오톡 버전, 패키지 규칙을 점검해 문제를 알려 줘요. **받지 않은 메시지 알림**에서는 어느 프로젝트에도 전달되지 않은 메시지 알림을 원인별로 세어 보여 줘요. |

### 패키지 규칙

기본값인 **규칙 자동 설정**이 켜져 있으면 카카오톡(`com.kakao.talk`)을 기기 기본 사용자 기준으로 읽고, 카카오톡 버전에 맞는 메시지 변환/분석 스펙을 골라요. StarLight가 켜져 있는 동안 카카오톡이 업데이트되어도 다음 메시지부터 맞는 스펙으로 바꿔요. 대부분은 바꿀 필요가 없어요.

카카오톡을 **듀얼 메신저**나 **업무 프로필**에서 쓴다면 자동 설정을 끄고 **규칙 목록**에 직접 추가해요.

| 항목 | 값 |
|---|---|
| **패키지명** | `com.kakao.talk` |
| **메세지 변환/분석 스펙** | Android 11 이상에서 카카오톡 26.7.0 이상은 `kakao_26_7`, 그보다 낮은 카카오톡은 `android_r`, Android 10 이하는 `default` |
| **유저 ID** | `0` 기본 사용자, `10` 업무 프로필, `11` 업무 프로필(샤오미), `95` 듀얼 메신저(삼성) |

아래쪽 저장 버튼을 눌러 저장해요. 직접 설정할 때는 규칙이 하나 이상 있어야 저장돼요. 규칙이 맞는지는 **문제 해결 도우미**로 확인할 수 있어요.

> [!NOTE]
> 카카오톡 26.7.0부터는 알림에서 방 이름을 Android 11 이상에서만 읽을 수 있어요. Android 10 이하에서는 방 이름 대신 보낸 사람의 이름이 들어오고 단체방도 1:1 방으로 보여요. 자동 설정을 끄고 `android_r`을 직접 지정해 두었다면 `kakao_26_7`로 바꾸세요.

## 미디어 전송

[`MediaSharer`](/docs/app/reference/script-api#파일-보내기-mediasharer-room.sendmedia)로 파일과 텍스트를 보낼 때의 설정이에요.

| 분류 | 항목 |
|---|---|
| **상태** | **카카오톡** 설치 여부, **다른 앱 위에 표시** 권한(StarLight가 백그라운드에 있을 때 카카오톡을 열려면 필요해요), **듀얼 메신저 카카오톡**으로 선택창 없이 보내기 위한 권한 |
| **전송** | **다운로드 제한 시간 (초)**(기본 30), **최대 파일 크기**, **연속 전송 간격 (×0.1초)**, **임시 파일 보관 시간 (초)**(기본 60), **전송 후**, **카카오톡 최대 체류 시간 (초)**(기본 5), **파일을 읽은 뒤 대기 (×0.1초)**(기본 5), **전송 로그 남기기** |
| **캐시** | **기본으로 캐시 사용**, **최대 캐시 파일 수**(기본 200), **최대 캐시 크기**, **캐시 비우기** |
| **채팅방** | **알려진 채팅방**(메시지를 받은 방이에요. 스크립트에서 채널 ID 대신 방 이름으로 지정할 수 있어요), **채팅방 목록 지우기** |
| **기록** | **최근 전송** |

**전송 후**는 스크립트가 `leave` 옵션을 주지 않았을 때 보낸 뒤 이동할 화면이에요. **홈 화면으로 이동**(기본), **StarLight로 돌아가기**, **카카오톡에 머물기** 중에서 골라요. 카카오톡의 채팅방이 열려 있는 동안에는 그 방의 알림이 오지 않아서 봇이 그 방의 메시지를 받지 못하니, 봇이라면 나가는 것이 좋아요. 카카오톡이 파일을 읽으면 **파일을 읽은 뒤 대기**만큼 기다렸다가 바로 나가고, 읽는 것이 보이지 않으면 **카카오톡 최대 체류 시간** 뒤에 나가요.

## 로그

**로그 파일 보관 기간**, **로그 탭 표시 개수**, **로그 파일 정리**가 있어요. [로그](/docs/app/guides/logs#로그-파일)를 보세요.

## 정보

| 항목 | 설명 |
|---|---|
| **업데이트 확인** | 새 버전을 확인해요. **업데이트 자동 확인**과 **업데이트 확인 채널**(STABLE, BETA, SNAPSHOT)을 정할 수 있어요. GitHub 판에만 있어요. Google Play 판은 Google Play에서 업데이트해요. |
| **앱 정보** | 앱 버전, PluginCore 버전, GitHub, 오픈소스 라이선스를 보여 줘요. |
| **개발자 돕기** | 개발자를 후원하는 방법이에요. |

> [!NOTE]
> 앱의 테마와 언어는 기기 설정(다크 모드, 시스템 언어)을 따라요. 에디터의 색 테마는 [에디터 설정](/docs/app/guides/editor#에디터-설정)에서 따로 바꿔요.

## 개발자 모드

**앱 정보**의 개발자 항목(무너)을 8번 누르면 **개발자 모드**가 열려요. 내부 로그 표시, 프로젝트의 **동시 실행 수** 변경 같은 실험적 기능이 들어 있어요. 무엇을 하는지 아는 항목만 바꾸세요.

**StarLight AI 문서**에서는 StarLight AI가 읽는 가이드, API, 이벤트, 타입 문서를 그대로 볼 수 있어요(StarLight 1.1.0 이상). 플러그인을 만든다면 StarLight AI가 플러그인을 어떻게 보는지 여기서 확인하세요. → [개발자 모드에서 확인하기](/docs/plugins/guides/starlight-ai#개발자-모드에서-확인하기)
